# 제출용 플레이 스크린샷 촬영 기록

GitHub 이슈 #360의 제출물 ③ 요구사항을 기준으로, 최신 `origin/main`(`ed718e4`)의 production build를 1920×1080에서 실제 플레이해 촬영했다.

## 공통 촬영 조건

- production build(`vite preview`)만 사용
- 실제 Gemini 판정 또는 게임이 제공하는 정상 fallback 흐름만 사용
- DEV 명령·fixture·화면 합성·AI 이미지 생성 미사용
- 제출본에는 브라우저 UI가 들어가지 않은 게임 화면 원본 PNG 사용

## 남은 촬영

- `07-affinity-level-comparison.png`: 친화도 Lv1/Lv3 비교 컷. 이슈에서 선택 항목이므로 필수 컷 완료 뒤 같은 주문·같은 화면 배율로 나란히 촬영한다.

보스 컷은 DEV·fixture·합성 없이 production 실제 플레이를 Xbox Game Bar 원본으로 녹화한 뒤, 브라우저 바깥 영역만 제외한 1920×1080 프레임으로 보존했다. 상단 화염 저항 `-15%`, 중앙 저항 안내, 따옴표 도발 대사가 한 화면에서 읽힌다.
