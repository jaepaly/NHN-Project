## 0. 한 줄 결정안

INCANT의 반복 동기를 영구 공격력 파밍으로 만들지 않는다.

**도감의 새로운 마법 발견 → 다음 런의 연구 주제 → 선택 가능한 기억 심도 → 빌드 검증 → 새 선택지 해금**으로 연결하고, LLM은 주문의 의미를 결정하되 실제 전투력은 스테이지와 런 빌드가 결정한다.

## 1. 왜 재설계가 필요한가

현재 게임에는 반복 플레이에 쓸 수 있는 시스템이 이미 많다.

- 주문 도감
- 승리 런 최고 주문을 다음 런의 Lv1 각인으로 사용하는 유산
- 누적 클리어 기반 런 격상
- 보스 처치 후 이어가기
- 친화 하나 계승
- 생성형 분기 맵
- 각인·정령·진화·융합·각성
- 플레이어의 영창을 기억하는 최종 보스

문제는 이 시스템들이 플레이어가 이해할 수 있는 하나의 목표로 연결되지 않는다는 점이다.

현재 반복 경험은 다음에 가깝다.

```text
런 종료 → 보스가 더 강해짐 → 유산 하나 선택 → 비슷한 전투를 다시 시작
```

### 1-1. 패배 후 눈에 보이는 보상이 약하다

도감은 쌓이지만 결과 화면에서 무엇이 새로 남았고 다음 런에서 무엇이 달라지는지 보여주지 않는다. 플레이어 입장에서는 실패한 8~12분이 사라진 것처럼 느껴질 수 있다.

### 1-2. 성공이 다음 런의 강제 불이익이 된다

현재 `runEscalation.ts`는 누적 클리어 수에 따라 폼 약화, 기믹, 보스 저항을 자동으로 강화한다. 잘한 결과가 다음 런의 선택지가 아니라 강제 난이도 상승으로 돌아온다.

### 1-3. 반복 난이도 축이 두 개다

- 누적 클리어 기반 `runEscalationTier`
- 보스 후 이어가기의 `loopIndex`

두 시스템이 별도로 적을 강화하므로 플레이어는 왜 어려워졌는지 읽기 어렵고, 개발자는 밸런스 원인을 분리하기 어렵다.

### 1-4. 보상 랜덤성이 빌드 형성을 방해한다

각인·정령·친화 시스템이 있어도 관련 카드가 나오지 않으면 최종 보스 전에 성장축이 완성되지 않는다. 랜덤성은 필요하지만 `아무 빌드도 되지 않은 런`은 줄여야 한다.

### 1-5. LLM power가 런 성장을 압도한다

현재 주문 power가 피해에 거의 1:1로 연결되고 일반 적 HP가 20~40 수준이다. 초반부터 power 80~100 주문이 그대로 적용되면 보상과 빌드 선택보다 강한 문장 하나가 더 중요해진다.

## 2. 목표 플레이 루프

```text
[타이틀]
기억 심도·연구 주제·유산 선택
        ↓
[2스테이지 분기 맵]
자유 영창·새 의미 서명 발견
        ↓
[런 내 빌드]
각인·정령·친화·각성
        ↓
[수문장 / 기억 보스]
현재 빌드와 이전 습관 검증
        ↓
[런 결산]
통찰·유산·새 연구·심도 해금
        ↓
[새로운 런] 또는 [심층 진입]
```

### 목표 지표

| 항목 | 목표 |
|---|---:|
| 1런 길이 | 8~12분 |
| 일반방 | 45~70초 |
| 수문장 | 60~90초 |
| 최종 보스 | 75~120초 |
| 일반방 수동 영창 | 3~5회 |
| 수문장 수동 영창 | 6~8회 |
| 최종 보스 수동 영창 | 8~12회 |
| 필살기 | 런당 1~2회 |
| 일반적인 최종 파워 | 시작 대비 ×1.6~2.0 |
| 최적 빌드 권장 상한 | 약 ×2.3 |
| 자동 피해 | 수동 지속 피해의 40% 이하 |

## 3. 메타 진행 — 마도 통찰

`마도 통찰`은 소비 재화가 아니라 누적 연구 경험치다. 포인트를 잘못 사용했다는 후회를 없애고, 일정 수치에 도달하면 새로운 플레이 방식과 도전 선택지가 열린다.

### 3-1. 획득 규칙

| 행동 | 통찰 |
|---|---:|
| 전투·정예·함정방 클리어 | +1, 런당 최대 4 |
| 수문장 처치 | +2 |
| 최종 기억 보스 처치 | +5 |
| 새로운 의미 서명 발견 | +1, 런당 최대 4 |
| 연구 주제 완수 | 최초 +3, 이후 런 재완료 +2 |
| 해당 기억 심도 최초 클리어 | +3 |

예상 획득량:

- 초반 패배: 2~5
- 중간 패배: 5~9
- 첫 승리: 15~21
- 고난도 승리: 기억 심도 배율 적용

패배해도 해당 런에서 얻은 통찰은 보존한다. 단, 초반 방 반복 파밍을 막기 위해 방 클리어 통찰과 신규 발견 통찰에 런당 상한을 둔다.

### 3-2. 신규 발견 판정

주문명은 LLM이 계속 새롭게 만들 수 있으므로 이름을 발견 단위로 사용하지 않는다. 다음 의미 서명을 사용한다.

```ts
type DiscoverySignature =
  `${SpellEffect}:${SpellElement}:${SpellElement | 'none'}:${SpellForm}`;
```

예:

```text
damage:fire:none:bolt
control:dark:none:cage
heal:light:none:nova
damage:water:lightning:wave
```

같은 구조의 주문명을 바꿔 통찰을 반복 획득할 수 없지만, 실제로 다른 기능·원소·형태를 만든 경우에는 새 발견으로 인정한다.

발견 대상은 **클라이언트 validator를 통과해 실제 실행에 진입한 일반 수동 영창**이다. Worker 원문, 주문명, 사후 도감 데이터에서 서명을 추정하지 않는다.

- 단일 일반 영창: 실행된 form spec에서 추출
- 일반 시퀀스: 실행된 form behavior별 추출, 한 영창 안의 동일 서명은 한 번만 인정
- `wait`: 제외
- `move`: PR #319 계약에서 제거됐으므로 대상 아님
- 필살영창: 일반 발견과 다양성 연구에서 제외
- 각인·정령·기본 공격 등 자동 실행: 제외

필살영창은 입력을 의도적으로 확장해 6~12개의 form과 과거 영창 공명을 만들기 때문에, 이를 일반 발견으로 세면 사용자가 직접 의도하지 않은 form까지 메타 보상이 된다. 필살영창은 별도 `ultimate-released` 목표로만 집계한다.

### 3-3. 연구 등급

> ⚠️ **개정 2026-08-06 (총괄 결정)** — 기본 연구 2종과 만물의 변주를 **통찰이 아니라
> 회차**로 옮겼다. 아래 통찰 표의 나머지 항목은 그대로다.
>
> | 완료 회차 | 해금 |
> |---:|---|
> | 0 (첫 런) | **원소 심화 · 정령 공명** |
> | 1 (2회차~) | **+ 만물의 변주** |
>
> 종전엔 `totalRuns >= 1 && insight >= 4`라 **첫 판에 연구가 아예 안 보였다**. 심사위원은
> 대개 한 판만 하고, 통찰은 `localStorage`에 쌓이므로 시크릿 창이면 항상 1회차다 —
> 소개 문서가 연구를 성장의 핵심으로 서술하는데 화면에 없으면 그게 더 나쁘다.
> 통찰 문턱 4는 방 4개만 돌면 채워져 **실질적인 벽은 회차뿐**이었고, 그 벽이 막던 게
> 하필 가장 최근에 만든 시스템이었다.
>
> 만물의 변주를 통찰(14)이 아니라 회차로 옮긴 이유는 **결정성**이다. 통찰 14는 완주해야
> 겨우 닿아 "2회차에 열린다"가 보장되지 않았다(일찍 죽으면 3·4회차까지 밀림).

| 누적 통찰 | 해금 |
|---:|---|
| 0 | 기본 런 |
| ~~4~~ → 회차 0 | P0 기본 연구 2종 |
| ~~14~~ → 회차 1 | 만물의 변주 (필살영창 연구는 통찰 14 유지) |
| 30 | 금기 연구와 유산 후보 새로고침 1회 |
| 50 | 고급 연구 기록·외형 표식 |

영구 공격력은 올리지 않는다. 해금되는 것은 시작 방향, 연구 목표, 위험 선택, 편의 선택이다.

## 4. 연구 주제 — 다음 런에서 해볼 것

**첫 런부터** 새 런 시작 전에 연구 주제를 제시한다(개정 2026-08-06 — 종전 "첫 런에는 요구하지 않는다"에서 변경, 위 3-3 참조). 1회차는 `원소 심화`·`정령 공명` 2택, 2회차부터 `만물의 변주`가 더해져 3택이 된다.

연구 주제의 시작 보너스는 **일반 보상 카드 한 장 이하**로 제한한다. 연구 목표에 맞는
행동이 단순 체크리스트로 끝나지 않도록 기본 연구는 단계마다 고정 상한의 런 내 보상과
플레이 규칙 변화를 지급한다. 시작 보너스와 3단계의 직접 수치 보상은 일반 카드 약 2장
수준으로 제한하고, 완료 특성은 특정 주문군을 계속 사용할 때만 작동하는 조건부 효율로 둔다.

### 4-1. 기본 연구

#### 원소 심화

- 이전 런 주력 원소 친화 +0.15로 시작
- 목표: 해당 원소로 서로 다른 폼 3개 시전
- 완료: 통찰 +3

이 연구는 `한 원소 집중은 숙련`이라는 기존 숙련 재설계 원칙을 따른다.

이전 런에 유효한 주력 원소가 없으면 이 연구를 후보에 넣지 않는다. 임의 원소를 자동 부여하지 않는다.

#### 수호 연구

- 시작 보호막 +20
- 목표: `heal`, `shield`, `buff`, `control` 목적의 일반 수동 영창 3회 성공
- 완료: 통찰 +3

한 시퀀스에 조건을 만족하는 behavior가 여러 개 있어도 연구 진행도는 영창당 최대 1 증가한다.

#### 기본 연구 단계 피드백

- 원소 심화: 새로운 형태 1종을 인정할 때마다 대상 원소 친화도 +0.05와
  사거리·범위 +10%를 누적한다. 완료 뒤에는 대상 원소 수동 영창 3회마다 가장 강한
  폼 하나를 25% 위력으로 공명 재시전한다.
- 수호 연구: 지원 영창 1회를 인정할 때마다 즉시 보호막 +8, 최대 +24를 얻는다.
  2단계부터 보호막이 남아 있는 동안 받는 전투 피해가 15% 감소한다. 완료 뒤에는
  지원 영창마다 보호막 +8을 다시 얻고 주변 일반 적을 밀어내는 결계 파동을 방출한다.
- 우상단에는 `●○○` 3칸 목표와 구체적인 연구 조건을 완료 때까지 상시 표시
- 진행 알림에는 인정된 형태/지원 영창과 이번 단계 보상을 함께 표시
- 완료 시 별도 돌파 배너로 마지막 단계 보상과 결산 통찰을 구분해 표시

### 4-2. 확장 기본 연구 — P0-D

#### 만물의 변주

- 다양성 최대 보너스 ×1.30 → ×1.50
- 구현 체감: 원소·형태의 더 적은 고유 개수를 진행 단계로 삼아 단계마다 최대 보너스 +0.05
  (`×1.30 → ×1.35 → ×1.40 → ×1.45 → ×1.50`)
- 목표: 여러 일반 수동 영창에 걸쳐 원소 4종과 폼 4종 사용
- 필살영창은 집계 제외
- 완료: 통찰 +3

#### 필살영창 연구

- 필살 게이지 25%에서 시작
- 목표: 유효한 `castMode='ultimate'` plan이 게이지를 소비하고 실행에 진입
- 완료: 통찰 +3

원격 실패, fizzle, invalid plan, 게이지 부족은 방출로 집계하지 않는다. 시작 게이지는 일반 `charge()`로 넣지 않고 공명 기록을 만들지 않는 전용 경로를 사용한다.

```ts
fusionGauge.seedCharge(FUSION_CONFIG.fullCharge * 0.25);
```

구형 `FusionGauge.tryRelease()` 자동 융합 방출은 제거한다. 게이지 소비와 연구 완료는 Shift+Enter로 진입해 검증된 `castMode='ultimate'` plan을 실행하는 단일 계약만 사용한다.

### 4-3. 연구 보상 지급 규칙

- 동일 런에서 같은 연구 완료 보상은 한 번만 지급
- 다른 런에서 같은 연구를 다시 완료하면 통찰을 다시 지급
- `completedContractIds`는 최초 완료·해금 기록에 사용
- 현재 런 지급 여부는 런 상태의 `rewardClaimed`로 별도 관리
- 1차값: 최초 완료 +3, 반복 완료 +2. 반복 보상은 플레이테스트 후 +2~3 범위에서 조정

### 4-4. 고급 금기 연구

금기 연구는 선택 사항이다. 명확한 제약 대신 통찰이나 보상 선택권을 더 준다.

| 연구 | 제약 | 보상 |
|---|---|---|
| 무유산 | 유산 각인 없이 시작 | 통찰 획득 ×1.5 |
| 단일 언령 금지 | 같은 의미 서명 연속 사용 불가 | 수동 주문 위력 +10% |
| 짧은 주문 | 8자 이하 영창만 허용 | 보상 카드 선택지 +1 |
| 불안정 마도 | 받는 피해 +20% | 정예·함정 보상 배율 증가 |

금기 연구는 기본 연구와 같은 풀에 섞지 않는다. 별도 시각 표식과 위험 설명을 제공한다.

## 5. 기억 심도 — 반복 난이도 통합

누적 클리어 기반 격상과 이어가기 난이도를 `기억 심도` 하나로 통합한다.

### 5-1. 규칙

- 심도 0은 항상 선택 가능
- 심도 N을 클리어하면 N+1 해금
- 타이틀에서 원하는 심도를 선택
- 보스 후 `심층 진입`을 고르면 현재 심도보다 한 단계 높은 난이도로 즉시 이어가기
- 최종 적용 심도는 하나의 식으로 계산

```ts
const effectiveDepth = selectedDepth + continuedLoopCount;
```

누적 클리어 수만으로 폼 약화나 난이도를 강제하지 않는다. 클리어 수는 심도 해금에만 사용한다.

### 5-2. 심도별 수치

| 심도 | 적 HP | 적 피해 | 주요 규칙 | 통찰 배율 |
|---:|---:|---:|---|---:|
| 0 | ×1.00 | ×1.00 | 기본 | ×1.00 |
| 1 | ×1.08 | ×1.10 | 정예 속성 증가 | ×1.15 |
| 2 | ×1.16 | ×1.20 | 저주방 본격 출현 | ×1.30 |
| 3 | ×1.24 | ×1.30 | 보스가 두 패턴 기억 | ×1.50 |
| 4 | ×1.32 | ×1.40 | 위험지대·소환 결합 | ×1.75 |
| 5 | ×1.40 | ×1.50 | 최종 보스 추가 페이즈 | ×2.00 |

HP 상승은 최대 40% 정도로 제한한다. 그 이후 난이도는 체력 스펀지가 아니라 패턴, 위험지대, 소환 조합, 기억 반응으로 올린다.

### 5-3. 저항 안전망

- 장기 기억 저항: 현행 ×0.85 유지
- 이번 런의 주력 카운터: 약 ×0.75
- 모든 페널티를 합친 최종 위력 배율 하한: ×0.5
- 충분한 친화 투자는 저항 일부 관통
- 보스가 저항하면 대사와 HUD로 원인을 반드시 표시

## 6. 런 내 보상 디렉터

랜덤 3택은 유지하되 각 카드의 역할을 분리한다.

| 카드 위치 | 역할 |
|---|---|
| 1번 | 현재 빌드를 발전시키는 카드 |
| 2번 | 생존·마나 경제 카드 |
| 3번 | 전체 풀에서 나오는 변칙 카드 |

### 6-1. 빌드 형성 보장

- 두 번째 보상까지 각인 또는 정령 후보를 최소 한 번 제시
- Lv2 각인·정령이 있으면 네 번째 보상부터 강화 카드 가중치 증가
- 진화·각성 조건이 완성됐다면 최종 보스 전 마지막 보상에 확정 등장
- 최근 수동 영창 원소를 친화 카드 원소에 가중
- 상한에 도달했거나 실제 적용할 수 없는 카드는 후보에서 제외
- 같은 시드와 같은 플레이 기록이면 같은 보상 후보를 재현

### 6-2. 패시브 중첩 상한

| 보상 | 권장 상한 |
|---|---:|
| 최대 HP | 3 |
| 최대 마나 | 2 |
| 마나 격류 | 2 |
| 수호 기점 | 2 |
| 신속 정령 | 3 |
| 친화 | 각성 이후에도 선택 가능, 효율은 완만하게 증가 |

랜덤성은 `어떤 빌드를 완성할까`에 작동해야 한다. `이번 런에는 아무 빌드도 완성되지 않는다`에 작동하면 안 된다.

## 7. 주문 전투력 모델

> **제출 P0 비범위.** PR #319 이후 현재 form별 전체 기대 피해량을 먼저 계측하고, 별도 R1 밸런스 PR에서만 적용 여부를 결정한다.

### 7-1. 역할 분리

```text
LLM: 주문의 의미·원소·형태·효과·원래 위력 결정
엔진: 현재 스테이지·빌드·대상 수에 맞는 실제 전투력 결정
```

자유 영창의 의미는 보존하면서 전투 밸런스는 결정론적 코드가 책임진다. 이때 원본 `plan.power`를 덮어쓰지 않는다.

```text
판정 power: LLM 의미 평가, 도감, 로그, 마나 비용
실효 전투 power: 스테이지·빌드·저항을 반영한 실행 예산
```

### 7-2. 스테이지 소프트캡

하드캡은 강한 표현을 무시하는 느낌을 주므로 초과분만 감쇠한다.

```ts
export function softCapPower(power: number, cap: number): number {
  if (power <= cap) return power;
  return cap + (power - cap) * 0.25;
}
```

| 구간 | 소프트캡 | 판정 power 100의 기초 전투력 |
|---|---:|---:|
| 스테이지 1 | 60 | 70 |
| 스테이지 2 | 80 | 85 |
| 최종 보스·융합 | 100 | 100 |

적용 순서:

```text
LLM 판정 power
→ 스테이지 소프트캡
→ 반복/다양성
→ 친화·버프
→ 폼별 피해 계수
→ 적 저항
```

소프트캡을 친화보다 먼저 적용해야 런에서 획득한 성장 보상이 그대로 살아난다.

일반 시퀀스는 behavior마다 소프트캡하지 않는다. plan 전체 전투 예산에 한 번 적용한 뒤 기존 `powerWeight`로 분배한다. behavior별 적용은 이중 감쇠가 된다. PR #319 필살영창은 스테이지와 무관하게 combat cap 100을 사용하는 별도 예산으로 취급한다.

### 7-3. 폼별 효율

아래 값은 **즉시 적용안이 아니라 계측 비교를 위한 가설값**이다. 현재 시퀀스 power 분배, 지속형 틱, 다중 타격, 오토 피해에 이미 계수가 있으므로 먼저 form별 전체 기대 피해량을 측정한다. 기존 기대 피해가 이미 정규화되어 있으면 새 계수를 추가하지 않는다.

| 폼 | 1차 계수안 |
|---|---:|
| bolt·slash 주 대상 | ×1.00 |
| beam·wave 대상당 | ×0.80 |
| nova·rain·zone 대상당 | ×0.60~0.70 |
| chain 첫 대상 | ×1.00 |
| chain 후속 대상 | ×0.70 → ×0.55 → ×0.40 |
| 지속형 전체 틱 합 | 대상당 power ×0.80~1.00 |

정확한 값은 적 HP가 아니라 방당 시간, 수동 영창 횟수, form별 전체 기대 피해를 기준으로 조정한다.

### 7-4. 적 체력 1차 시작값

> **별도 R1 밸런스 PR 후보.** P0-A~C와 함께 변경하지 않는다.

| 적 | 현재 | 스테이지 1 제안 | 스테이지 2 |
|---|---:|---:|---:|
| 사수 | 20 | 35 | S1 ×1.30 |
| 추격자 | 30 | 45 | S1 ×1.30 |
| 분열체 | 40 | 60 | S1 ×1.30 |
| 소형 분열체 | 10 | 15 | S1 ×1.30 |
| 실드셋 | 현행 기준 | 일반 적 ×1.50 | S1 ×1.25 |
| 정예 | 기본형 기준 | ×2.20~2.50 | 심도 배율 별도 |

이 표는 확정값이 아니라 플레이테스트 시작값이다. 목표 시간을 만족하면 수치를 더 올리지 않는다.

### 7-5. 필살기

`FUSION_CONFIG.fullCharge=120`은 PR #319와 #317 정합 확인 후까지 유지한다. 연구와 UI에서는 `융합 필살기` 대신 PR #319 계약에 맞춘 `필살영창` 명칭을 사용한다.

합격 기준:

- 플레이어의 70% 이상이 수문장 전후에 게이지 준비 완료
- 한 런 평균 방출 1~2회
- 준비됐지만 트리거하지 못한 비율 20% 이하

충전은 됐는데 트리거 인식 때문에 못 쓰는 문제가 해결된 뒤에도 기준 미달이면 120→100으로 낮춘다. 연구용 25% seed는 게이지만 채우고 원소·form·effect·최근 주문 공명에는 기여하지 않는다.

## 8. 보스 역할

### 8-1. 수문장 — 현재 런의 규칙 학습

- 심도 3 이상: 두 번째 기억 패턴 추가

## 11. 회귀·밸런스 검증

### 11-1. 자동 회귀

- 동일 의미 서명은 주문명이 달라도 통찰을 한 번만 지급
- 일반 수동 영창만 신규 발견으로 인정
- 필살영창·각인·정령·기본 공격은 일반 발견과 다양성 연구에서 제외
- 일반 시퀀스 한 번에 동일 서명이 여러 번 실행돼도 한 번만 인정
- 수호 연구는 한 영창에 지원 behavior가 여러 개여도 진행도 최대 1
- 신규 발견 통찰은 런당 4 제한
- 패배해도 획득 통찰 보존
- 동일 런의 연구 완료 보상 중복 지급 금지, 다른 런에서는 재획득 가능
- 실패한 필살 plan은 `ultimate-released`와 연구 진행을 발생시키지 않음
- 연구 시작 게이지 seed는 공명 기록을 만들지 않음
- 심도 N 클리어 전에는 N+1 선택 불가
- 이어가기는 `selectedDepth + continuedLoopCount`
- 동일 시드·프로필이면 연구 카드와 보상 후보가 동일
- 메타 시작 보너스는 일반 보상 카드 한 장 이하
- 자동 피해는 수동 지속 피해의 40% 이하
- 모든 페널티를 합친 최종 위력 배율은 ×0.5 이상
- 저장 데이터 손상·구버전·용량 초과 시 게임 정상 시작

### 11-2. 플레이테스트 합격 기준

- 첫 사망 또는 첫 승리 후 새 진행을 확인할 수 있음
- 결과 화면에서 다음 행동을 10초 안에 이해
- 두 번째 런 시작 선택 과정 15초 이하
- 3개 시드 플레이에서 서로 다른 빌드 2개 이상 형성
- 일반방 평균 수동 영창 3~5회
- 최종 보스 평균 수동 영창 8~12회
- 필살기 런당 1~2회
- 같은 강한 문장 반복이 최적 전략이 아님
- 비공격 영창 연구를 실제로 완수 가능
- 심도 상승이 HP 스펀지보다 패턴 변화로 먼저 체감됨

### 11-3. 로컬 계측 항목

외부 분석 서비스 없이 기존 플레이 로그에 다음을 추가한다.

## 12. 제출 전 구현 범위와 컷라인

### P0-A — 의미 서명·통찰 저장 기반

- `MetaProfileV1`과 `incant:meta:v1` 저장
- 일반 수동 영창의 검증된 실행 plan에서 의미 서명 추출
- 한 영창 내부·프로필 전체 중복 제거
- 신규 발견 통찰 런당 최대 4
- 방 클리어 등 최소 통찰 계산
- 패배·승리 모두 통찰 보존
- 저장 손상·구버전·실패 안전 복구
- 순수 회귀

연구 UI, 시작 보너스, 기억 심도, 전투 power 변경은 넣지 않는다.

### P0-B — 최소 런 결산 표시

- 이번 런 신규 발견 목록
- 이번 런 획득 통찰
- 누적 통찰과 다음 해금까지 남은 수치
- 승리·패배 공통 적용
- 기존 데이터로 가능한 대표 빌드·수동 영창 횟수 표시

이 단계까지가 **최소 제출 합격선**이다.

### P0-C — 기본 연구 2종과 최소 해금 연결

- 누적 통찰 4 이상에서 연구 선택 해금
- 첫 런에는 선택을 요구하지 않음
- 새 런 시작 전 `원소 심화` / `수호 연구` 2택
- 시작 보너스와 진행 추적
- 완료 통찰 지급과 결과 화면 표시
- 선택 과정 15초 이하

`P0-A+B+C`를 **제출 권장 목표**로 확정한다.

### P0-D — 확장 기본 연구 2종

- `만물의 변주`
- `필살영창 연구`
- 일반 발견과 필살영창 집계 완전 분리
- 공명 없는 필살 게이지 seed 경로

P0-C 안정화 후에만 추가한다.

### P0-E — 기억 심도 0·1 최소 도입

- 심도 0 항상 선택 가능
- 심도 0 클리어 시 심도 1 해금
- 타이틀에서 0·1 선택
- 심도 1에 적 HP·피해 소폭 증가
- 누적 클리어 기반 강제 form 약화 제거
- 기존 `loopIndex`는 삭제하지 않고 후속 통합 인터페이스만 준비

일정과 실런 결과에 따른 **조건부 추가 범위**다.

### P0-F — 전체 기억 심도 통합

- 심도 2~5
- `effectiveDepth = selectedDepth + continuedLoopCount`
- 저주방·보스 기억 패턴·통찰 배율 단계 해금
- 기존 강제 격상 축 완전 제거

이번 제출 P0에서 분리한다.

### P1 — 런 품질·전투 밸런스

1. 보상 디렉터 3슬롯 역할 분리
2. 각인·정령 성장 보장 규칙
3. form별 전체 기대 피해 계측
4. 스테이지 소프트캡 적용 여부 결정
5. 적 HP·form 계수·필살 충전 별도 튜닝

메타 저장과 전투 피해 공식 변경을 한 PR에 넣지 않는다.

### P2 — 명시적 후순위

1. 금기 연구
2. 유산 후보 새로고침

4. 추가 보스 페이즈

### 명시적 비범위

- 영구 공격력 트리
