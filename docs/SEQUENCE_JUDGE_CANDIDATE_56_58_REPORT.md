# 영창 Judge 후보 56~58 — 전면 `spell_plan` 실험

## 결론

후보 58은 모든 성공 cast를 `spell_plan`으로 통일하면서 기존 최소 의미 계약과
원자 주문의 즉시 발동감을 보존했다. 실험 Worker 버전은
`98aace9c-30d1-46e3-b961-64f9c51abfb2`이며 프로덕션에는 반영하지 않았다.

## 확정한 출력 계약

- 모든 cast는 `spell_plan`만 출력한다.
- 닫힌 단일 사건은 `80ms`, 1 sequence, 1 form인 원자 plan이다.
- 이동·순서·반복·동시·변화가 명시되지 않았더라도 자연스러운 가능성이 있으면
  복합 plan을 적극 검토한다.
- 갈라짐·분열·개화·변신·융합·붕괴·부활·각성은 시작과 결과를 구분하는 강한
  변화 신호로 보고 최소 두 실행 사건을 요구한다.
- 기존 `spell` 응답은 호환 입력으로만 받아 의미를 추가하지 않고 원자 plan으로
  승격한다.

## 단계별 결과

### 후보 56

- 최초 12종은 배포 전파 중 구·신 버전이 섞여 평가에서 제외했다.
- 전파 완료 재측정은 12/12 HTTP 200, 모든 cast가 plan이었다.
- 원자 대조군 4종은 모두 `80ms·1 form`을 유지했다.
- `황혼이 갈라진다`, `심연의 개화`가 확률적으로 원자화되어 변화 규칙을 보강했다.

### 후보 57~58

- 후보 57은 변화 과정어를 강화했지만 `황혼이 갈라진다`가 한 차례 원자화됐다.
- 후보 58은 강한 변화 신호의 원자 출력만 한정 재판정하고 해당 입력을 복합
  타임아웃 대상으로 분류했다.
- 후보 58 표적 4종:
  - `황혼이 갈라진다`: damage form 2개, 1.2초
  - `심연의 개화`: control→damage 2단계, 1.4초
  - `파이어볼`: damage form 1개, 80ms
  - `새벽의 방패`: shield form 1개, 80ms
- 표적 4/4 HTTP 200, 1.317~2.640초였다.

## 후보 58 전체 검증

### 신규 12종

- 12/12 HTTP 200
- 원자 6종 / 복합 6종
- 닫힌 원자 대조군은 모두 80ms
- `천공의 장례`, `우주의 심장박동`, `달의 선회`의 과정·반복·순환이 복합으로
  표현됐다.
- `별을 삼킨 파도`는 wave 하나로 포식 이미지를 표현한 허용 경계 사례다.

### 기존 대표 30종

- 30/30 HTTP 200
- `spell_plan` 30 / legacy `spell` 0
- 원자 16종 / 복합 14종
- 평균 응답 1.643초, 최대 2.688초
- 기존 자동 하한선 95/100, 자동 만점 24/30

과거 single/sequence 권장 모드는 전면 plan 계약과 직접 비교하지 않는다. 95점은
원소·형태·필수 관계 같은 최소 계약 보존율로만 사용한다.

## 남은 품질 이슈

- `얼어붙은 추격전`과 `겨울 정원의 폐막`이 명시적 ice를 water로 판정했다.
  전면 plan 전환과 별개인 원소 의미 보존 문제로 후속 후보에서 다룬다.
- `화산맥의 기상`, `불사조의 낙화`는 기존 기대보다 짧은 한 단계로 나왔다.
  실제 화면에서 충분한 장면인지 수동 시각 평가가 필요하다.
- `팔원소 대합창`은 8원소·4 form을 보존했지만 1.6초로 과거 선호시간보다 짧다.
- `불멸의 행진`은 move+shield로 나와 공격성 기대와 맞는지 플레이테스트가 필요하다.
