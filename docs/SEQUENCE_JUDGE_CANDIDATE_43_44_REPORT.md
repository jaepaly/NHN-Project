# 영창 Judge 후보 43~44 — 비이동 연사 안무

## 목표

`연사`, `속사`, `연발`, `잇달아`처럼 개별 탄의 시간차가 핵심인 공격을 단일
spell로 축약하지 않고, `form → wait → form`의 박자가 보이는 시퀀스로 만든다.
반대로 동시 사격, 지속형 beam·zone, 밀집 범위기, 명시적 단발은 불필요하게
분할하지 않는다.

## 설계 경계

- 횟수 미지정 연사는 2~3발이며 현재 기본값은 3발이다.
- `두 발`, `세 번`, `4회`처럼 횟수가 명시되면 form 수를 그대로 보존한다.
- 발사 사이에는 wait-only sequence를 두며 N발은 N-1개의 wait를 갖는다.
- `한꺼번에`, `동시에`, `일제사격`은 동시형 또는 rain으로 해석하고 wait를
  만들지 않는다.
- `계속 유지`, 지속 beam·zone은 하나의 지속 form으로 유지한다.
- 전체 위력은 plan 단위로 공유한다. 탄 수만큼 총 피해를 복제하지 않는다.
- 후보 44의 구조 보정은 모델이 이미 선택한 단일 spell의 spec만 재사용한다.
  새 원소·효과·형태를 추론하지 않는다.

## 후보별 결과

### 후보 43

프롬프트 규칙과 완전 JSON 예시를 추가했다. 명시적 횟수인
`빛의 화살을 네 번 연발한다`는 4 form·3 wait로 나왔고 동시·지속·단발
대조군도 보존됐다. 하지만 횟수 없는 `마력탄 연사`는 여전히 단일 spell로
축약되어 프롬프트만으로는 목표를 충족하지 못했다.

### 후보 44

단일 spell로 축약된 시간차 연사에만 적용되는 좁은 구조 보정을 추가했다.

- `마력탄 연사` 3회 반복: 3/3 모두 3 form·2 wait
- `별빛 탄환 두 발 연발` 3회 반복: 3/3 모두 2 form·1 wait
- 추가 LLM 재요청 없음
- 실험 Worker 버전: `6a159cd9-d07c-4caf-bb6f-de6eef51f03b`

## 신규 12종 최초 개봉

구현 전에 시간차 연사 6종, 동시형 2종, 지속형 2종, 밀집 범위기 1종,
단발 1종의 기대값을 봉인했다.

- HTTP 200: 12/12
- 자동 하한선: 평균 100/100, 만점 12/12
- 권장 모드: 12/12 일치
- 시간차 연사 6종: 모두 필요한 form 수와 wait 존재
- 동시·지속·밀집·단발 대조군 6종: 모두 single, wait 없음
- 응답 시간: 1.348~2.582초

자동 점수는 스키마에서 관찰 가능한 최소 계약만 확인한다. 실제 탄 간격,
각 탄의 화면상 구별, 전체 공격의 타격감은 인게임 수동 시각 평가가 필요하다.

## 기존 30종 회귀

- HTTP 200: 30/30
- 자동 하한선: 평균 96.9/100, 만점 27/30
- 필수 모드 계약: 4/4 유지
- 실제 sequence: 12/30
- 후보 41 대비 자동 하한선 95.8→96.9, 선호 모드 일치 19→18

선호 모드 1건 변동은 생성형 응답의 표본 변동 범위로 볼 수 있으나, 신규 연사
규칙이 기존 추상 영창의 복합성을 장기적으로 낮추지 않는지는 반복 측정과 인게임
검토에서 다시 확인한다.

## 결론과 후속

후보 44는 연사 계열의 단일 축약을 해결했고 대조군과 필수 계약을 보존했다.
실험 단계의 당면 목표는 달성했다. 프로덕션에는 반영하지 않았으며, 다음 단계는
인게임에서 연사·명시 횟수·동시형·지속형·단발을 함께 비교하는 수동 플레이테스트다.
