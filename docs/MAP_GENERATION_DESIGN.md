# 맵 구조 생성 설계 및 검증 기준

## 1. 목적

런의 방을 고정 순서로 나열하지 않고, 스테이지마다 분기와 합류가 있는 유향 비순환 그래프(DAG)를 생성한다. 플레이어는 미니맵에서 방의 성격을 보고 경로를 선택하며, 위험한 경로는 그에 상응하는 보상을 기대할 수 있어야 한다.

이 문서는 맵 생성기의 설계 기준과 검증 규칙을 정의한다. 시각적 확인은 별도 쇼케이스 HTML을 사용한다.

## 2. 방 종류와 위험/보상 값

| 기호 | 방 종류 | 전투 여부 | 위험도 | 보상도 |
| --- | --- | --- | ---: | ---: |
| C | 일반 전투 | 전투 | 1 | 0 |
| E | 엘리트 | 전투 | 2 | 0 |
| T | 함정/저주 | 전투 | 2 | 0 |
| $ | 보물 | 비전투 | 0 | 1 |
| A | 제단 | 비전투 | 1 | 1 |
| B | 보스 | 별도 처리 | 경로 비교에서 제외 | 경로 비교에서 제외 |

위 값은 맵 경로 비교용 상대값이다. 실제 전투 수치·보상 수량과 직접 일치할 필요는 없다.

## 3. 그래프와 파티션

각 스테이지는 시작방에서 보스방으로 이어지는 DAG다. 방 그래프는 파티션을 이어 붙여 생성한다.

파티션 표기 `a>b(n)`의 의미는 다음과 같다.

- `a`: 파티션 시작 시 분기 수. 최대 3.
- `b`: 파티션 종료 시 유지되는 분기 수. `a >= b`.
- `n`: 파티션 내부 경로의 평균 길이.

지원 범위는 `1>1`, `2>1`, `3>1`, `2>2`, `3>2`, `3>3`이다. 분기는 선택지를 만들고, 합류는 그래프 복잡도가 과도하게 증가하는 것을 막는다.

중요: **시작방만 일반 전투(C)로 고정한다.** 합류점은 일반 방과 동일한 배치 후보이며, 일반 전투로 강제하지 않는다.

## 4. 경로 성격

분기 경로는 다음 성격 중 하나를 사용한다.

- 저위험·저보상
- 중간 위험·중간 보상
- 고위험·고보상

분기가 둘이면 저위험·고위험 경로를, 셋이면 세 성격을 모두 사용한다. 경로 길이는 랜덤 요소로 사용하되, 긴 경로가 자동으로 고위험이 되지 않도록 방 종류와 함께 조정한다.

## 5. 우선순위

맵 생성과 후처리는 아래 순서를 따른다. 상위 항목을 깨서 하위 항목을 만족시키지 않는다.

### 0. 구조적 필수 조건

- 시작방에서 보스방까지 모든 노드가 연결된다.
- 고립 노드와 순환이 없다.
- 파티션의 분기·합류 연결이 유효하다.
- **개별 시작-보스 경로의 방 시퀀스가 중복되지 않는다.** 파티션 단위가 아니라 실제 선택 가능한 전체 경로를 비교한다.

### 1. 시작방

- 각 스테이지의 시작방은 일반 전투(C)다.

### 2. 보상 최소 보장

- 각 스테이지 그래프 전체에는 보물($) 또는 제단(A)이 최소 하나 존재한다.

### 3. 위험/보상 정합성

두 경로를 비교할 때, 다음 지배 관계를 금지한다.

> A의 위험도가 B보다 높고, A의 보상도가 B보다 낮다.

위험도가 높고 보상이 같은 경우, 또는 위험도가 같고 보상이 다른 경우는 허용한다. 이는 모든 선택지를 단일 정답으로 수렴시키지 않기 위한 의도적인 규칙이다.

### 4. 방 다양성

0~3을 만족하는 후보 사이에서 아래를 최대화한다.

1. 특수방 4종 `E/T/$/A`의 존재 수
2. 시작방 외 일반 전투(C) 존재 여부

특수방 4종 또는 일반 전투를 넣는 것이 0~3을 깨면 해당 요구는 포기한다. 다양성은 필수 제약이 아니라 가산점이다.

### 5. 전투/비전투 비율

스테이지 전체 노드 기준으로 `C/E/T`를 전투, `$ / A`를 비전투로 계산한다.

- 목표: 전투 70~75%, 비전투 25~30%
- 룸 수가 적을 때의 60%, 66.7%, 77.8%, 80% 같은 이산값은 허용한다.

### 6. 전투방 세부 비율

일반 전투(C), 엘리트(E), 함정/저주(T)가 한 종류로 과도하게 쏠리지 않도록 조정한다. 단, 룸 수가 부족하거나 상위 우선순위와 충돌하면 가장 먼저 양보한다.

## 6. 다양성 후보 탐색

위험/보상 보정이 끝난 뒤, 시작방과 보스방을 제외한 방을 대상으로 후보 조합을 탐색한다.

후보는 다음을 모두 만족할 때만 유효하다.

- 구조와 시작방 고정 유지
- 개별 경로 시퀀스 중복 없음
- 보상방 최소 1개 유지
- 위험도 증가·보상도 감소 지배 관계 없음

유효 후보 중 특수방 종류 수가 높은 쪽을 우선하고, 동률이면 시작방 외 일반 전투가 있는 쪽을 선택한다. 이 탐색은 맵 규모가 작은 현재 스테이지에서만 수행하므로 비용이 제한적이다.

## 7. 검증 방식

무작위 시드마다 다음을 검사한다.

1. 모든 노드가 시작-보스 경로에 포함되는지
2. DFS 기준 실제 순환이 없는지
3. 전체 시작-보스 경로 시퀀스가 중복되지 않는지
4. 시작방이 C인지
5. 보상방이 최소 하나 있는지
6. 위험/보상 지배 관계가 없는지
7. `E/T/$/A`를 넣을 수 있는 해가 있는데 현재 결과가 이를 놓치지 않았는지
8. 특수방 다양성을 낮추지 않고 C를 추가할 수 있는 해가 있는데 현재 결과가 이를 놓치지 않았는지

7~8은 현재 배치만 보는 검사가 아니다. 가능한 방 종류 조합을 탐색해 0~3을 유지하는 대안이 있는지 확인한다. 따라서 구조상 불가능한 경우는 정상 예외로 분류한다.

### 예상 런타임

런타임은 실제 가능한 시작-보스 경로의 평균으로 계산한다. 분기 때문에 그래프에 존재하지만 플레이어가 한 런에서 모두 방문하지 않는 방을 합산하지 않기 위함이다.

| 항목 | 예상 시간 |
| --- | ---: |
| 일반 전투(C) | 47초 |
| 함정·저주(T) | 54초 |
| 엘리트(E) | 60초 |
| 보물($) / 제단(A) | 20초 |
| 스테이지 보스(B) | 78초 |
| 최종 보스(B) | 90초 |
| 전투·보스 후 선택 | 발생당 9초 |
| 포탈 선택 | 방 전환당 3초 |
| 방 전환 연출 | 방 전환당 1초 |

방 목표시간은 첫 웨이브 생성부터 마지막 적 사망까지의 활성 실제 시간이다. 영창 입력·원격 판정·시퀀스 실행은 포함하고 명시적 일시정지, 보상 선택, 포탈 선택, 방 전환은 제외한다.

런타임 식에서는 고정 90초 오버헤드를 사용하지 않는다. 일반·함정·엘리트방과 두 보스 뒤의 선택에는 각각 9초를 적용한다. 최종 보스 뒤에는 보상 카드 대신 종료·이어하기 선택이 발생한다. 보물·제단방의 20초에는 해당 방의 상호작용이 포함된다. 방문한 방 사이에는 포탈 선택 3초와 전환 연출 1초를 적용한다.

목표 범위는 8~12분이다. 이 값은 전투 밸런스와 실제 플레이테스트 결과에 따라 후속 조정할 수 있다.

## 8. 검증 결과

현재 생성기 기준 5,000 시드(10,000개 스테이지) 검사 결과:

| 항목 | 위반 수 |
| --- | ---: |
| 연결·고립 노드 | 0 |
| 실제 순환 | 0 |
| 개별 경로 중복 | 0 |
| 시작방 C 위반 | 0 |
| 보상방 누락 | 0 |
| 위험/보상 지배 관계 | 0 |
| 가능한 특수방 4종 배치 누락 | 0 |
| 가능한 시작방 외 C 배치 누락 | 0 |

현재 검증 표본에서 0~4 우선순위의 “가능한데 생성기가 놓친” 사례는 없다.

예상 런타임 검증 결과는 다음과 같다.

| 항목 | 결과 |
| --- | ---: |
| 평균 | 10분 16초 |
| 중앙값 | 10분 09초 |
| 최단 | 8분 35초 |
| 상위 5% 경계 | 11분 28초 |
| 최장 | 11분 45초 |
| 8~12분 범위 충족 | 5,000 / 5,000 시드 (100%) |
| 8분 미만 | 0개 |
| 12분 초과 | 0개 |

현재 방 수는 DAG의 분기·합류와 방 종류 다양성을 보존한다. 목표시간은 초기 플레이테스트 기준이며, 실제 중앙값이 크게 벗어나면 방 수보다 전투 프리셋의 적 수·조합·웨이브를 먼저 조정한다.

한 맵 내부의 경로별 성장 기회 차이는 위험·보상 선택을 구성하므로 제한하지 않는다. MapGraph 런타임 통합 후 서로 다른 시드 사이의 맵 전체 평균 기대 성장 기회 편차를 측정하고, 유의미한 차이가 확인될 때만 이어하기 강화 보정을 검토한다. 실제 선택 경로와 획득 성장량은 적 스탯이나 보정식에 사용하지 않는다.

## 9. 쇼케이스 사용법

`docs/prototypes/partition-map-generator.html`은 시드 입력, 맵, 범례만 남긴 쇼케이스용 생성기다.

- `C`: 일반 전투
- `E`: 엘리트
- `T`: 함정/저주
- `$`: 보물
- `A`: 제단
- `B`: 보스

팀 검토 시에는 대표 시드를 선정해 단순 구조, 2분기, 3분기, 긴 구조, 다양성 정상 예외를 함께 확인한다.
