# 영창 Judge 기존 30종 재감사

> 작성일: 2026-07-30  
> 대상: `SEQUENCE_JUDGE_EXPECTATIONS.json`의 초기 30종  
> 목적: 단일/시퀀스 적중률이 아니라, 사용자식 시적·함축적 입력에서 자연스럽게 읽히는
> 복수의 시각 사건을 보존하면서도 입력에 없는 게임 효과를 창작하지 않는 기준을 확정한다.

## 1. 이번 재감사의 원칙

1. 추상적이라는 이유만으로 시퀀스를 만들지는 않는다.
2. 입력 안에서 **형성·이동·전개·변화·결말**처럼 역할이 다른 사건을 둘 이상 자연스럽게
   읽을 수 있으면 복합 구성에 약한 우선권을 준다.
3. 복합 구성은 여러 sequence뿐 아니라 같은 sequence의 병렬 behavior도 포함한다.
4. 단계 수를 늘리기 위한 장식성 `move`, `wait`, 무관한 공격·회복·강화는 금지한다.
5. 단일 결과도 핵심 이미지·규모·속도·공간 성격을 충분히 보여주면 합격할 수 있다.
6. `single_preferred`와 `sequence_preferred`는 자동 합격/실패의 절대 정답이 아니라
   수동 시각 평가의 우선 방향이다. `sequence_required`만 구조 의미 소실을 자동 실패로 본다.
7. 이동 시간 수치의 구체적인 재설계는 신규 held-out 이동 사례를 추가한 뒤 수행한다.

## 2. 분류 의미

| 분류 | 의미 |
|---|---|
| 단일 우선 | 한 사건·한 공간 효과로 핵심 이미지가 완결된다. |
| 복합 약우선 | 단일도 가능하지만 역할이 다른 복수 사건을 자연스럽게 펼칠 수 있다. |
| 복합 필수 | 반복·병렬·이동 관계 등 구조를 잃으면 입력의 핵심 의미가 사라진다. |
| 양쪽 가능 | 단일 압축과 복합 전개가 비슷하게 자연스러워 화면 결과로 판단한다. |

## 4. 기존 expectation에서 바꿀 항목

### 복합 약우선으로 상향

- `도망치는 별`: `either` → `sequence_preferred`
- `그림자 바느질`: `either` → `sequence_preferred`
- `사방의 포화`: `single_preferred` → `sequence_preferred`
- `별자리를 꿰매는 바늘`: `either` → `sequence_preferred`
- `뇌광의 사냥`: `either` → `sequence_preferred`
- `심연의 군세`: `either` → `sequence_preferred`

이 변경은 입력에 없는 사건을 의무화하지 않는다. 단일 출력도 핵심 이미지와 과정이
충분히 보인다면 수동 평가에서 통과할 수 있다.

### 양쪽 가능으로 조정

- `사슬을 끊는 파도`: `single_preferred` → `either`
- `태풍의 회랑`: `single_preferred` → `either`
- `모래시계의 수호`: `single_preferred` → `either`

### 복합 필수로 상향

- `유성우를 거슬러`: `sequence_preferred` → `sequence_required`

유성우 환경과 이를 거스르는 시전자 이동이 함께 있어야 핵심 문법 관계가 보존된다.

### 계약 모순 교정

- `불사조의 낙화`: `requiredBehaviorTypes`의 player `move`를 제거한다.
  현재 설명·금지 관계는 player move를 금지하면서 필수 행동에는 move를 남겨 서로 모순된다.

### 이번에는 수치를 바꾸지 않는 항목

- `찰나의 전이`를 비롯한 이동 속도별 `durationMs`
- 복합 출력의 단계별 `durationWeight`
- 효과군별 `effect` 기대값

위 항목은 신규 held-out 사례로 순간이동·돌진·일반 이동·느린 이동과
heal·shield·buff·control·summon을 확장한 뒤 재설계한다.

## 5. 다음 검증

1. 이 재분류를 반영한 기존 30종 자동 점수는 **품질 개선 수치가 아니라 새 하한선**으로 기록한다.
2. 현재 후보 17 결과를 새 기준으로 정적 수동 재평가한다.
3. 실제 사용자식 시적·함축적 입력 중심의 신규 held-out 세트를 작성한다.
4. held-out 최초 측정 전에는 프롬프트를 수정하지 않는다.
5. 이후 수정은 기존 30종 비퇴행, held-out 일반화, 인게임 시각 만족도를 함께 통과해야 한다.

## 6. 후보 17 재채점

저장된 후보 17 응답을 새 expectation과 수정된 채점 의미로 다시 평가했다.

- 자동 하한선: **92/100**
- 자동 항목 만점: **23/30**
- 권장 모드 일치: **21/30**
- 자동 실패 항목: **16개**
- 수동 판정 항목: **47개**

`sequence_preferred`와 `single_preferred`의 불일치는 자동 실패가 아니라 수동 판정으로
변경했다. 선호 모드는 예외적으로 더 만족스러운 반대 형식을 허용한다는 기존 계약과
일치시키기 위한 수정이다. `sequence_required` 불일치와 원소·form·필수 관계 위반만
자동 실패로 유지한다.

이 수치는 후보 17이 새 방향을 92% 만족한다는 뜻이 아니다. 복합 약우선으로 재분류한
`도망치는 별`, `천둥새의 비행`, `그림자 바느질`, `사방의 포화`,
`별자리를 꿰매는 바늘`, `심연의 군세`가 실제로는 단일 출력이므로 수동 시각 평가가
필요하며, 권장 모드 일치 21/30이 현재 복합성 방향의 더 직접적인 신호다.
