# INCANT — 말이 곧 마법이 되는 로그라이크

> **NHN 2026 Game × AI Hackathon 사전과제 제출작**

**정해진 스킬은 없습니다.** 플레이어가 입력한 문장을 LLM이 실시간으로 판정해
원소·형태·위력을 가진 마법으로 구현합니다. 그리고 **보스는 당신이 쓴 주문을 기억합니다** —
애용한 원소에는 저항이 생기고, 회차가 쌓일수록 세계가 당신의 수를 읽습니다.
살아남으려면 매 순간 새로운 말을 창작해야 합니다.

설치 불필요 · 데스크톱 브라우저 · 별도 API 키 없이 실제 LLM 판정이 동작합니다.

## 무엇이 다른가

**① 문장이 곧 주문이다**

`원소 8 × 형태 13 × 효과 6 × 상태이상 6 × 위력 0~100` 공간 위에서, 자유 문장이
그때그때 다른 마법이 됩니다. "얼음 감옥에 가둬라"는 빙결 속박이 되고, "불태워 서서히
녹여라"는 지속 화상이 됩니다.

**② AI가 고르는 게 아니라 설계한다**

한 문장을 여러 단계로 쪼개 **순서와 간격까지** 정합니다. "불덩이를 세 번 연달아,
마지막은 크게"라고 쓰면 `form → wait → form`으로 박자가 짜입니다. 명시적인 연사는
간격으로, 동시에 일어나는 사건은 병렬로 갈립니다.

> 창의는 LLM이, 규칙은 게임이 쥡니다. 실행 가능한 계획이 아니면 거부하고, 위력·마나·
> 시간 제한은 로컬 검증기가 소유합니다. 판정이 실패해도 **게임은 멈추지 않습니다**
> (캐시 → 타임아웃 → Mock 폴백).

**③ 기억하는 세계 — 그리고 나도 기억한다**

보스는 지난 런들의 주문 이력을 학습해 저항·카운터로 대응합니다. 플레이어도 마찬가지로,
런을 클리어하면 최고의 주문이 주문서에 기록되어 다음 런을 유산으로 시작합니다.

**④ 연구 주제가 빌드를 가른다**

런을 시작할 때 연구 주제 하나를 고릅니다. 완료하면 그 런 내내 작동하는 지속 효과가
붙습니다 — 같은 원소를 파거나(메아리), 정령에 투자하거나(공명탄), 매번 다르게
쓰거나(무지개 파동). **무엇을 연구했느냐가 곧 어떻게 싸우느냐**입니다.

## 플레이 방법

**목표** — 분기형 지도를 따라 8개의 방을 돌파해 마지막 **기억의 주인**을 처치합니다.
HP가 0이 되면 런이 끝나지만, 그 런의 주문 이력은 세계에 남습니다.

| 입력 | 동작 |
|---|---|
| **WASD** | 이동 |
| **Enter** | 영창 모드 — 슬로모션 속에서 문장 입력 |
| **Shift+Enter** | 필살 영창 (게이지 만충 시) |
| **A / D** · **W / S** | 보상 카드 · 다음 방 선택 |
| **ESC** | 일시정지 — 전체 경로 지도와 빌드 상세 |

기본 공격은 가장 가까운 적에게 자동으로 나갑니다. 플레이어가 정하는 것은
**무엇을 말할지**와 **어디에 설지**입니다.

## 로컬 실행

```bash
npm install
npm run dev     # http://localhost:5173/NHN-Project/
```

별도 설정 없이 **실제 Gemini 판정**이 동작합니다. API 키는 Cloudflare Worker 프록시의
서버 시크릿이라 클라이언트가 알 필요가 없습니다. 오프라인이면 Mock 판정으로 자동
전환되어 그대로 플레이할 수 있습니다.

```bash
npm test        # 회귀 106종
npm run build   # 프로덕션 빌드 (dist/)
```
